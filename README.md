## 🌱 세상에 없던 에너지 순환 놀이 시스템 SEEKOO

#### 2025 예술적인 소프트웨어 대상
#### 개발기간 : 2025.04-2025.10

## 👋🏻 프로젝트 소개

스마트폰과 태블릿 사용이 일상이 된 환경 속에서,
아이들의 실외 활동 감소·신체 활동 부족·자연과의 단절은
더 이상 개인의 문제가 아닌 사회적 과제가 되었습니다.

SEEKOO는 아이들을 다시 자연 속 ‘탐험가’로 이끄는
에너지 순환 기반 놀이 시스템입니다.

아이들은 태양과 움직임이라는 자연 에너지를
직접 발견하고, 만들고, 사용하며
놀이를 통해 에너지의 원리와 환경의 소중함을 몸으로 배우게 됩니다.

SEEKOO는 단순한 교구가 아닌,
놀이–탐험–에너지–학습이 하나로 이어지는 경험을 설계합니다.
